# Kamalnath G — Game Developer Portfolio

A static portfolio built with HTML, CSS, and JavaScript. No backend or build tools required.

## Preview
Open `index.html` in a browser. Google Fonts require an internet connection; system fallbacks are included.

## Project screenshots
The page preserves the original asset paths under `assets/`: `laser-dodger.jpg`, `hotel-simulation.jpg`, `mazescape.jpg`, `whack-it-all.jpg`, `hard-ball.jpg`, `fly-me.jpg`, `pokeball-catcher.jpg`, and `memorize.jpg`.
Copy your existing `assets` folder into this directory if you have it. Until then, project cards display gradient placeholders.

## Existing links
Original project download links, resume URL, phone number, email, LinkedIn, and Instagram URLs have been retained.

## GitHub Pages
Upload all files and the `assets` folder to the root of a GitHub repository. In Settings → Pages, select deploy from the `main` branch and `/ (root)`.

## Gameplay videos
Open `script.js` and paste a YouTube link into the `video` field of a project, for example `video:"https://www.youtube.com/watch?v=XXXXXXXXXXX"`. Watch, youtu.be, shorts and embed links all work. Leave it `""` for no video. The video loads only when a visitor clicks the play button.
Note: YouTube may refuse to play when `index.html` is opened straight from your computer (file://). It works once the site is on github.io, or when served locally with `python -m http.server`.
